Links

Palm OS software has been fading off the web for two decades. Where the original page is gone, these point at the Internet Archive instead.

pilot-link

J-Pilot talks to your handheld through pilot-link, so you need it installed. J-Pilot 2.1.0 needs 0.15.0 or newer, which rules out most distribution packages — pilot-link was dropped from Debian after buster, and the last version it carried was 0.12.5.

  • Upstream

    github.com/desrod/pilot-link

    The official home of pilot-link, maintained by David Desrosiers. This is where 0.15.0 comes from, and where to report a pilot-link problem.

  • Packaged

    pilot-link in the J-Pilot apt repository

    The easiest route on Debian and Ubuntu: the same repository that carries J-Pilot also carries pilot-link 0.15.0 and libpisock-dev, so adding it once gets you both. See Download for the command.

  • Archived

    pilot-link on SourceForge

    Release tarballs up to 0.12.x, from when the project lived there.

  • Archived

    pilot-link.org, as it was

    The original home page, preserved by the Internet Archive. The domain stopped resolving years ago.

Other Palm software

  • Historical

    J-Pilot in Debian

    Debian carried J-Pilot up to buster, where it stopped at 1.8.2. It is no longer in the archive — use the apt repository instead. The package tracker still has the history.

  • Active

    GNU Keyring

    The Palm encryption application that J-Pilot's KeyRing plugin reads.

  • Dormant

    PilotManager

    Another desktop application for Palm OS devices.

  • Dormant

    Visor USB support

    The SourceForge project for getting Handspring Visors talking over USB.

  • Archived

    Henrik Becker's J-Pilot page

    Translated documentation and other material. The site is gone; this is the Internet Archive's copy.
