Extending it

Plugins

J-Pilot loads plugins as shared libraries, so a plugin can add a whole application of its own. Three ship with J-Pilot; the rest were written by other people over the years.

Bundled with J-Pilot

Installed by the jpilot-plugins package, or built from the source tree.

Expense

Syncs the Palm Expense application — entries, categories, currencies, and payment types.

Source →

KeyRing

An interface to the GNU Keyring Palm encryption application, so your encrypted records are readable on the desktop.

Source →

SyncTime

Sets the clock on the Palm device to the desktop's time during a sync. Not the same thing as the SyncTime Palm application.

Source →

Writing your own is documented in the plugin manual.

Third-party plugins

Written by other people, and listed here as they were announced. Most are old and unmaintained — expect to do some work to build them against a current J-Pilot.

  • 2009-02-15

    jpilot-icalendar

    A standalone program that imports RFC 2445 (iCalendar) events into J-Pilot. To-dos are not supported, and full two-way synchronisation was intended but never finished, so it is an importer rather than a conduit. Its author called it alpha; back up first. Downloads are on SourceForge, last updated in 2013.

  • 2008-05-27

    Pics & Videos

    Downloads pictures, photos, and videos from the newer Palm Treo and Palm Centro phones. Reads both internal flash and the SD card.

  • 2002-02-06

    jpilot-backup

    Jason Day's enhanced backup plugin. It keeps up to 99 archived backups, takes them automatically — every sync, or daily, weekly, or monthly — and lets you choose which databases to include and which to skip.

    Jason's site has gone, but the plugin outlived it: it is still packaged by Fedora. The same page also carried SyncMal, a MalSync client that pulled down web pages for reading later; that one does not appear to have survived.

  • 2000-10-30

    pilot-mailsync

    Syncs mail with your Palm. The page it lived on at the University of Bonn no longer resolves.

  • 2000-03-10

    jpilot-Mail

    Another way to sync mail with your Palm.

  • 2000-02-15

    JustInTime

    A work-around for the SyncTime plugin crashing Palm OS 3.3. The plugin is not broken — Palm OS 3.3 is. You need the Palm application installed as well.

Several of these plugins have outlived the pages they were hosted on. If you have a working copy of one, or a link that still resolves, please say so on the mailing list and it can go back on this page.
