What it does

Features

J-Pilot covers the four core Palm applications and the newer Contacts, Tasks and Memos databases, and allows you to do things a desktop is good at: a real keyboard, a big screen, printing, and exports you can use elsewhere.

Palm applications

  • Datebook, Address, ToDo, and Memo Pad
  • The newer Calendar, Contacts, Tasks and Memos databases
  • Monthly and weekly views of the Datebook/Calendar
  • Repeating events, and exceptions to those events
  • Editing a single occurrence of a repeating event
  • “By day” repeats that fall on the last week of a month, not just the fourth
  • Your existing Palm preferences are used, so sorting order for addresses, todos, and memos matches the handheld
  • Categories sync both ways, and can be edited on the desktop
  • Quick find in the Address application
  • Limited support for Japanese Kanji: SJIS → EUC → SJIS

Sync and backup

  • Two-way synchronization, fast and slow syncs
  • A full backup, or a sync of just the supported applications
  • Restore capability
  • USB connectivity
  • Palm OS 4.x passwords
  • Install applications and files onto the Palm, including Graffiti shortcuts

Import and export

  • Import and export in many different formats
  • iCalendar export from the ToDo/Tasks and Datebook/Calendar applications
  • vCard export from the address book/contacts
  • LDIF export from the address/contacts book
  • CSV, for anything that reads a spreadsheet

Plugins

  • Expense — The Palm expense app — ships with J-Pilot
  • KeyRing — An interface to the GNU Keyring Palm encryption application — ships with J-Pilot
  • SyncTime — Sets the clock on the Palm device — ships with J-Pilot
  • Third-party plugins, including jpilot-backup, are listed here
  • A documented plugin API, so you can write your own

Third-party application support

  • DateBk3, DateBk4, DateBk5, and DateBk6 tags
  • The PEdit Palm application

And more

  • Small and fast, designed to take up very little screen space
  • Global search across applications
  • PostScript printing
  • An integrated telephone dialer
  • Color theme files to make it interesting
