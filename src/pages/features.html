What it does

Features

J-Pilot covers the four core Palm applications and the newer Contacts and Memos databases, and adds the things a desktop is good at: a real keyboard, a big screen, printing, and exports you can use elsewhere.

Palm applications

  • Datebook, Address, To Do List, and Memo Pad
  • The newer Contacts and Memos databases (Calendar and Tasks are not supported yet)
  • Monthly and weekly views of the Datebook
  • Repeating events, and exceptions to those events
  • Editing a single occurrence of a repeating event
  • “By day” repeats that fall on the last week of a month, not just the fourth — try a monthly appointment on the fourth week of a month with no fifth occurrence of that day
  • Your existing Palm preferences are used, so sorting order for addresses, to-dos, and memos matches the handheld
  • Categories sync both ways, and can be edited on the desktop
  • Quick find in the Address application
  • Limited support for Japanese Kanji: SJIS → EUC → SJIS

Sync and backup

  • Two-way synchronization, fast and slow syncs
  • A full backup, or a sync of just the supported applications
  • Restore capability
  • USB connectivity and Palm OS 4.x passwords
  • Install applications and files onto the Palm, including Graffiti shortcuts

Import and export

  • Import and export in many different formats
  • iCalendar export from the To Do and Datebook applications
  • vCard export from the address book
  • LDIF export from the address book
  • CSV, for anything that reads a spreadsheet

Plugins

  • Expense, shipped with J-Pilot by default
  • KeyRing, an interface to the GNU Keyring Palm encryption application
  • SyncTime, which sets the clock on the Palm device
  • jpilot-backup, for keeping multiple backups
  • A documented plugin API, so you can write your own

Third-party application support

  • DateBk3, DateBk4, DateBk5, and DateBk6 tags
  • The PEdit Palm application

Everything else

  • Small and fast, designed to take up very little screen space
  • Global search across applications
  • PostScript printing
  • An integrated telephone dialer
  • Colour scheme files, to theme the interface
