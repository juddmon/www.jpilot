Getting help

Mailing lists

There is one general J-Pilot list. It is where releases get announced, bugs get reported, new features get argued about, and new users get help.

Posting

Once you are subscribed, write to jpilot@lists.jpilot.org.

Subscribing

Send a message to jpilot-request@lists.jpilot.org with join or subscribe as the subject or in the body.

For the list of commands the address understands, send the same address a message with help as the subject or in the body.

Archives, and the web forum

The list runs on Mailman 3, whose web interface is called Empathy. It works as a forum as well as an archive: create an account there and you can read old threads and reply to messages in the browser, exactly as you would on any web forum. Replies posted that way go out to the list like any other mail.

The account works both ways — if you are already subscribed by email, you already have one.
