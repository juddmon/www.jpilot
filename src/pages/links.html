Links

Palm OS software has been fading off the web for two decades. Where the original page is gone, these point at the Internet Archive instead.

pilot-link

J-Pilot talks to your handheld through pilot-link, so you need it installed. Its old home at pilot-link.org stopped resolving some years ago; these are the places it still lives.

  • Packaged

    pilot-link in Debian

    The simplest route on Debian, Ubuntu, and their derivatives — apt install pilot-link libpisock-dev. Note that J-Pilot {{version}} needs {{pilot_link}} or newer.

  • Source

    pilot-link on GitHub

    David Desrosiers' repository, and the closest thing to an upstream today.

  • Source

    pilot-link on SourceForge

    The old release tarballs.

  • Archived

    pilot-link.org, as it was

    The original home page, preserved by the Internet Archive.
