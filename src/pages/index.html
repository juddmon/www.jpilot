Palm OS desktop · Linux · Unix

Your Palm handheld, at home on your desktop.

J-Pilot syncs your Palm OS device's datebook, addresses, to-dos, and memos — and keeps them where you actually work.

What it does

Everything on your Palm, mirrored on the desktop.

Two-way sync with the four core Palm applications and the newer Contacts and Memos databases, plus plugins, imports, exports, and printing.

Palm apps

  • Datebook, Address, To Do, Memo
  • Newer Contacts & Memos
  • Monthly & weekly views
  • Repeating events & exceptions
  • Uses your Palm's own preferences

Plugins

  • Expense (bundled)
  • KeyRing encryption
  • SyncTime — set the device clock
  • jpilot-backup — multiple backups

Import / export

  • iCalendar from Datebook & To Do
  • vCard from the address book
  • LDIF and CSV
  • Many other formats

Sync & more

  • Two-way fast and slow syncs
  • Full backup and restore
  • USB and Palm OS 4 passwords
  • PostScript printing · dialer
  • Global search across apps

Get it

Install J-Pilot {{version}}

There is an apt repository for Debian and Ubuntu. Everything else — packages, source, and older releases — is on the download page.

Heads up: {{version}} needs pilot-link {{pilot_link}} or newer, because of a change to the Contact blob API. Building needs libpisock-dev ≥ {{pilot_link}}; running it needs libpisock9.

The repository covers Ubuntu 22.04, 24.04, and 26.04, and the matching Linux Mint releases. Source tarballs and signatures are on GitHub releases. 

# Add the apt repository
curl -s https://packagecloud.io/install/repositories/judd/jpilot/script.deb.sh | sudo bash

# Install J-Pilot and the bundled plugins
sudo apt install jpilot jpilot-plugins
