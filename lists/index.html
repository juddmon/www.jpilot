Getting help

Mailing lists

There is one general J-Pilot list. It is where releases get announced, bugs get reported, new features get argued about, and new users get help.

Posting

Once you are subscribed, write to jpilot@lists.jpilot.org.

Subscribing

Send a message to jpilot-join@lists.jpilot.org. The subject and the body are ignored, so both can be empty — only the address matters. You will get a reply asking you to confirm.

To leave, write to jpilot-leave@lists.jpilot.org the same way. Mail from the list also carries a List-Unsubscribe header, so many mail programs offer a one-click unsubscribe of their own.

You can also subscribe from the list page in the browser, which is the easier route if you would rather have a web account as well.

Archives, and the web forum

The list runs on Mailman 3, and its member interface is called Empathy. It works as a forum as well as an archive: create an account there and you can read old threads and reply to messages in the browser, exactly as you would on any web forum. Replies posted that way go out to the list like any other mail.

The account works both ways — if you are already subscribed by email, you already have one.
